# Lab10 — Q-러닝 강화학습

---

## 학습목표

- [ ] Q-Learning 수식 `Q(s,a) ← Q(s,a) + α[r + γ·maxQ(s',a') − Q(s,a)]` 이해
- [ ] ε-greedy 탐험/활용 균형 이해
- [ ] 4x4 그리드 환경에서 에이전트 학습 관찰
- [ ] 하이퍼파라미터 조정 실험

---

## 파라미터 설명

| 파라미터 | 기호 | 의미 |
|---------|------|------|
| Learning Rate | α | Q값 업데이트 폭 (0~1) |
| Discount Factor | γ | 미래 보상의 현재 가치 (0~1) |
| Epsilon | ε | 탐험 확률 (1.0=완전탐험) |
| Epsilon Decay | — | 매 에피소드마다 ε 감소율 |

---

## 그리드 환경

```
[ 0][ 1][ 2][ 3]
[ 4][X5][ 6][ 7]
[ 8][X9][10][X11]
[12][13][14][G15]

G = 목표 (+10 보상)
X = 함정 (-10 보상)
일반 셀 = -0.1 (이동 패널티)
```

---

## 씬 설정 방법

1. **Agent** Empty GameObject 생성
2. `QLearningAgent.cs` 추가
3. **Play** → 자동으로 훈련 시작
4. OnGUI에서 에피소드 진행 및 최적 정책 확인
5. 훈련 완료 후 Console에 최적 정책(화살표) 출력

## 기본 과제

- [ ] 5000 에피소드 후 최적 정책 화살표 방향 확인
- [ ] `learningRate = 0.5`로 변경 시 수렴 속도 비교
- [ ] `epsilon = 0.1`로 시작하면 어떻게 되는지 관찰
